Prelude for Guile Scheme, an opt-in enhancement to the standard library.

/kracht/ means power/strength in the Dutch language

kracht is also a recursive acronym which stands for:
KRACHT Reliable And Consistent Helper Tools

If you like my work, please support me by [[https://bmc.link/jjbigorra][buying me a cup of coffee ☕]] so I can continue with a lot of motivation.
